Deploy

  1. Get the branch

    # from your local clone
git fetch origin
git checkout claude/tactical-hex-grid-battlefield-odngvz
git pull

    If you'd rather ship from main, merge first — git checkout main && git merge claude/tactical-hex-grid-battlefield-odngvz. It fast-forwards; main hasn't moved since the work began. Deploying straight off the branch works too: Wrangler uploads whatever public/ holds, it doesn't care which branch you're on.

  2. Authenticate Wrangler

    npx wrangler login
npx wrangler whoami   # should name your account, not "not authenticated"

  3. Sanity-check before uploading

    node _synckcheck.mjs              # expect: ALL CLEAN
node _harness.js public/index.html # expect: ALL CHECKS PASSED

    Both were green at the last commit. Run them anyway — they take seconds and they catch a bad merge before it reaches the edge.

  4. Deploy

    npm run deploy

    deploy.mjs minifies public/index.html, runs npx wrangler deploy, then restores your un-minified source. The restore fires even on Ctrl+C or a killed shell — but if you ever find the file minified locally, git checkout -- public/index.html puts it right.

    Don't trust the deploy log. It says "success" the moment Cloudflare accepts the upload, which is not the same as the edge serving it. Step 5 is the real check.

  5. Verify at the edge, and poll

    curl -s "https://mythicspellbook.xyz/version.txt?cb=$(date +%s)"
# expect: v120x4

    Propagation across points of presence takes up to a couple of minutes, so repeat this until it flips rather than concluding anything from the first call. The cache-buster matters — version.txt is the file the in-game update check fetches uncached, and a stale CDN copy is exactly what would fool you.

    Once it reads v120x4, hard-reload the game. Existing players get the update prompt on their next check because the service worker's CACHE_VERSION changed with it.

What to look at first

Start a battle. In rough order of "would tell you something's wrong":

  • The board is a hex field, 14 wide by 12 deep, filling its slot — not a plate floating on a painting.
  • W A S D pans, Q and E turn, R snaps back to the default view.
  • Select a unit: one continuous contour around everywhere it can reach. Hover a destination: the arrow bends around obstacles rather than cutting straight.
  • Walk a unit somewhere that needs a detour — the sprite should follow the arrow, not slide through the wall.
  • Click a unit's feet and it selects. That's the regression the final gate caught and closed; it's the one most worth spot-checking.
  • Move a unit onto a ruin and loot it — the salvage grid that opens is the same one tombstones use, including dragging your own loot back in to make room.
  • Hold two SCP trucks for three turns in a row and the match should end without anyone touching a hero.

If you need to roll back

There's no partial state to unwind — no schema change, no data migration. Rolling back is redeploying the old front end.

# fastest: previous deployment, from the Cloudflare dashboard
#   Workers & Pages → playmythicspellbook → Deployments → Rollback

# or from source
git checkout main            # 4dbc4f9, pre-project
…bump all three version knobs to something NEW…
npm run deploy

The bump on the way back matters as much as on the way out. Roll back to v120x3 or lower and clients already holding v120x4 will not see a change — the update check compares against what they have. Go forward to v120x5 even when the code goes backward. The three that must move together are public/version.txt, window.BUILD_VERSION in public/index.html, and CACHE_VERSION in public/sw.js.

Two things left open

Both cosmetic, both documented, neither blocking a deploy:

  • The route ribbon isn't drawn on the receiving client. In multiplayer, an opponent's unit walks the correct bent route, but the arrow itself isn't shown to you while it happens. The walk is right; the telegraph is missing. Cause is a gate in the telegraph push that only the local AI narrator ever satisfies.
  • Sub-pixel feathering at some unit feet. Ground rings and shadows are clipped with the body's plane rather than their own ground plane, leaving a few dozen pixels of softness at the disc rim. Invisible at 1×; measurable at high zoom.
