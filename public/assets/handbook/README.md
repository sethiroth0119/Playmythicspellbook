# Handbook art

Drop the Player's Handbook cover image here as **`cover.png`**.

The book looks for `assets/handbook/cover.png` first and falls back to the
Birth of Universe pack art if it is not there, so the page renders either way —
but the cover is the one image the book cannot pull from the existing card
library, because it is the book's own artwork.

Anything else you want in the handbook can live wherever it already lives:
the editor's image picker indexes the whole card/board/location library.
